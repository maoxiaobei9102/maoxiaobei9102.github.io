今天简单介绍一下本站的技术架构与主题。

## 技术架构

本博客采用 **Hugo** 作为静态站点生成器，结合 **GitHub Pages** 托管，并通过 **GitHub Actions** 实现自动化构建与部署。

- **Hugo**：以内容为中心的超快静态站点生成器，使用 Go 编写，输出纯静态页面。
- **GitHub Pages**：免费、稳定的静态站点托管服务，直接集成 GitHub 仓库。
- **GitHub Actions**：每次推送到 `main` 分支，自动构建 Hugo 站点并发布到 Pages，做到「改完即上线」。

## 主题

本站使用 **Ananke** 主题（Hugo 官方默认主题之一），简洁、响应式，支持多语言。

主要特性包括：

- 响应式布局，适配各类屏幕
- 默认中文（`zh-cn`）语言支持
- 背景配色跟随系统：默认浅色，系统深色时自动切换为黑色
- 页头与页脚展示 GitHub 关注链接
- 代码块复制按钮、SEO 元信息等
